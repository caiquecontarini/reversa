# 🤝 Contribuindo para Reversa

Obrigado por querer contribuir! Este guia vai ajudar.

## Como Reportar Issues

1. Verifique se já existe issue similar
2. Seja específico: título claro + descrição detalhada
3. Inclua: versão, passos para reproduzir, comportamento esperado

## Como Contribuir com Código

### Setup Local

```bash
git clone https://github.com/caiquecontarini/reversa.git
cd reversa
npm install
```

### Workflow

1. Fork o repositório
2. Crie branch: `git checkout -b feature/meu-feature`
3. Commit: `git commit -m "feat: descrição clara"`
4. Push: `git push origin feature/meu-feature`
5. Abra Pull Request

### Padrões de Código

- Markdown: use `.markdownlint.json`
- YAML: use `.yamllint`
- Commits: use conventional commits (feat:, fix:, docs:, etc)

## Discussões

- 💬 **Ideas**: Sugestões de features
- ❓ **Q&A**: Dúvidas sobre uso
- 📢 **Announcements**: Novidades e releases
- 🎉 **Show & Tell**: Projetos que usam Reversa
